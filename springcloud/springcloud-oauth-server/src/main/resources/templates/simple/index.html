OAuth2 授权服务器 - 接口测试工作台 Spring Authorization Server | 支持动态测试
系统说明 & 测试工具

本服务为 OAuth 2.1 / OIDC 授权服务器，支持 授权码模式、客户端凭证模式、刷新令牌。 为方便验证接口，每一行都提供了 ▶ 测试 按钮，点击可打开 通用请求调试器， 支持自定义 Headers（如 Authorization: Bearer xxx）、请求体（JSON / 表单文本等）， 并可实时发送请求并查看响应。

测试小贴士：
- 需要 Bearer Token 的端点（如 /userinfo），请在测试面板添加请求头：Authorization: Bearer <access_token>
- 令牌端点 /oauth2/token 通常需要 Content-Type: application/x-www-form-urlencoded 及 client 认证 (Basic Auth 或表单参数)
- 测试面板会携带浏览器 Cookie，已登录的会话可直接测试需认证的页面（如 /logout）。
