图片跨域获取示例

这个示例演示了如何使用带有Referer头的fetch API获取跨域图片资源。请注意，由于跨域策略和CORS限制，部分图片可能无法正常加载。

重要说明

本示例使用了特定的Referer头(https://your-authorized-domain.com)来请求图片资源。如果目标服务器没有配置允许此Referer访问，或者图片资源受CORS策略限制，请求可能会失败。在实际使用时，请确保你有权访问目标资源并遵守相关服务条款。
