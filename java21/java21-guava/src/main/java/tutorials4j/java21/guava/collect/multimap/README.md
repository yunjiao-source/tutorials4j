### 🎯 如何选择？

| 实现类                | 允许重复 value | 保持插入顺序 | 自动排序 | 适用场景                               |
|----------------------|---------------|-------------|---------|----------------------------------------|
| `ArrayListMultimap`  | ✅            | ✅          | ❌      | 通用首选，允许重复，按添加顺序访问        |
| `LinkedListMultimap` | ✅            | ✅          | ❌      | 需要频繁在值列表中间插入/删除             |
| `HashMultimap`       | ❌            | ❌          | ❌      | value 必须唯一，不关心顺序，性能优先      |
| `LinkedHashMultimap` | ❌            | ✅          | ❌      | value 必须唯一，但要保留添加顺序          |
| `TreeMultimap`       | ❌            | ❌（但排序） | ✅（键和值均排序） | 需要键或值按自然/自定义顺序排列           |

选择时，先确定 **是否允许重复**，再决定 **是否需要顺序**，最后看是否需要 **排序**。如果都不确定，先用 `ArrayListMultimap` 准没错。如果数据量巨大且去重很重要，考虑 `HashMultimap`。
