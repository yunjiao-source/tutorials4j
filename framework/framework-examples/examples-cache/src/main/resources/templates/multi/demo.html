🔄 相同ID重复请求将直接从缓存中获取，不再调用数据库（观察后端日志确认）

💡 工作原理 多级缓存机制

✅ L1 本地缓存 (Caffeine)：进程内缓存，极快访问速度。
✅ L2 分布式缓存 (Redis)：多实例共享，保证数据一致性。
✅ 查询顺序：L1 → L2 → 数据库，数据库查询结果会同步写入L1和L2。
✅ 演示效果：第一次请求某个ID会打印“数据库中获取数据”，第二次及以后请求相同ID不再打印，证明缓存生效。
