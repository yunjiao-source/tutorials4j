Redisson 分布式锁工坊

基于注解 @RedissonBlockLockable · @RedissonReentrantLockable | 演示自动续期 & 固定租约

锁粒度: 订单ID
测试参数 & 锁策略
order:
相同订单ID → 锁互斥；不同订单ID → 完全并发。
锁调用接口
阻塞锁 (Block Lock) — 一直等待直到获取锁，无等待超时
可重入锁 (Reentrant Lock) — 支持重入，可设置获取锁等待超时
注解参数说明
• expireTime ≤ 0 → 看门狗自动续期 (默认每10秒续期至30秒)
• expireTime > 0 → 固定租约，到期自动释放锁，业务未完成则失去保护
• waitTime (仅可重入锁) → 尝试获取锁的最大等待时间，超时抛出异常
• 本演示业务随机休眠 0~9 秒，用于模拟耗时操作。
两种锁行为对比
阻塞锁获取失败则无限阻塞，直到获得锁
可重入锁支持重入 + 等待超时(waitTime)，超时快速失败
⏱️ 自动续期业务未完成时锁自动续期，避免误释放
⏲️ 固定租约严格限制锁持有时间，适合短任务
