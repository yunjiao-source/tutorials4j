测试特性
✅ 支持连续点击（并发请求），每个请求独立记录日志。
✅ 相同订单ID下所有锁类型order:{orderId} 互斥，可体验排队/锁竞争。
✅ 阻塞锁永久等待锁；可重入锁等待3秒超时抛出 LockCreateException。
✅ 自动续期适用于长业务，固定租约超时自动释放锁，注意业务耗时阈值。
