Redis 分布式锁 · 深度测试

基于 Lua 脚本原子锁 + 自动续期/固定租期 | 模拟订单业务并发场景

后端：Spring Boot + Redis
测试原理： 同一订单号(orderId) 的请求会竞争分布式锁。
✅ 自动续期模式（expireTime ≤ 0）：看门狗机制，业务执行期间锁持续续期，其他请求必须等待锁释放（立即失败）。
⚠️ 固定租期模式（当前 expireTime = 3000 ms）：锁固定3秒后自动释放，若业务耗时超过3秒，锁提前失效，可能造成并发入侵 （可观察控制台日志&下方并发测试）。
