测试建议
快速验证锁互斥效果
• 同一订单ID 快速连续点击 同一种模式 → 第二次请求会因锁冲突返回失败。
• 自动续期模式：业务随机sleep 0~9秒，锁会一直保持，其他请求直到锁释放才能获取。
• 固定租期(3秒)：若业务sleep超过3秒，锁提前释放，可能导致并发入侵（后端日志会体现）。
• 观察下方实时日志，看到响应状态码和错误信息即可验证锁行为。
后端接口信息
  • GET /redis/non-expire-time?orderId={id} → 自动续期锁
  • GET /redis/expire-time?orderId={id} → 固定过期锁(3s)
  • 业务随机睡眠0~9秒，模拟处理耗时。锁竞争失败返回5xx错误。
