📋 调用结果
正在请求后端接口，后端生成签名并调用支付...
👆 点击上方按钮，将调用 /signature/test 接口，后端通过 SignatureClient 自动完成签名并请求 /signature/pay，支付成功后返回结果。
🔍 流程说明：
① 前端 → GET /signature/test?userid=&amount=
② 后端 SignatureClient 生成 timestamp, nonce, 计算签名 并附加到请求头
③ 后端向 /signature/pay 发起签名POST请求
④ 服务端 @RequiredSignature 验证签名及时间窗口(60s) → 执行业务逻辑 → 返回结果
⑤ 前端展示最终支付响应
⚡ 提示
如果签名验证失败，请检查服务器时间是否同步，默认 appKey = appkey1 ，服务端已预置该密钥。
