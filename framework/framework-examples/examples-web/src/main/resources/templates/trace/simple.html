测试面板说明 — 点击任意卡片上的「发起请求」按钮，即可调用对应的后端接口。
✅ 正常接口返回字符串；⚠️ 异常接口将触发全局异常处理器，前端展示 HTTP 状态和错误详情。
📡 WebFlux 接口 (Mono) 与普通接口使用方式一致，后端采用响应式架构。
