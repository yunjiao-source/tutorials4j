🛡️ 幂等性接口

@Idempotent · 同一会话仅一次成功

接口地址：GET /annotation/idempotent
行为：同一 X-Session-Id 首次请求成功，后续请求抛出幂等异常 (IdempotentException)。

@AccessLimited(maxTimes = 4)

接口地址：GET /annotation/access-limited
行为：同一 X-Session-Id 最多请求 4次，超出限制抛出 AccessLimitedException。

测试指引
▪ 幂等测试：相同 Session ID 重复点击“调用幂等接口”，首次成功，之后均返回错误。
▪ 频率限制测试：相同 Session ID 连续点击，前4次成功，第5次返回限流错误。点击「刷新并生成新ID」重置所有计数。
▪ 所有请求均在请求头中自动添加 X-Session-Id: <当前会话ID>。
▪ 后端基于 X-Session-Id + URI 生成唯一键，切换ID即视为全新客户端。
